# The trusted items of the verified core: every item of crates/safeverbs-core that Verus
# takes on trust (`external_body`, an external specification) is listed here, one per line
# as `<file> <item>`, and scripts/verify.sh refuses any other. Ghost state conjured with an
# `assume_new` constructor may appear only inside these items. docs/verification.md
# (section "Trusted computing base") says why each is trusted.
